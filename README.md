LTspiceの波形解析で「.measの測定点がグラフのどこにあるか分からない」
「毎回カーソルを合わせて探すのが大変」とお悩みではありませんか？
本動画では、プロットファイル（.plt）に測定点マーカーや計算結果一覧を自動追加するPythonツール
『GraphAnnotation』をご紹介します！
手動での位置確認作業をゼロにし、TRAN/DC解析の可読性を劇的に向上。
スミスチャート補助円の描画や、安心の自動バックアップ・復元機能（--rollback）も搭載しています。
